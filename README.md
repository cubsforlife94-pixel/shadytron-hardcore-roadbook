# Shadytron Hardcore Roadbook

Personalized Old School RuneScape Hardcore Ironman progression dashboard for Shadytron — from the Moons of Peril green log toward confident raiding.

Live site: https://shadytron-hardcore-roadbook.cubsforlife94.chatgpt.site

## What is inside

- Route phases with persistent goal checklists.
- Moons of Peril collection-log tracking.
- Anti-burnout pivot deck for bossing, questing and skilling swaps.
- Cost-conscious skill calculator with XP, time and GP estimates.
- Slayer command center with master selection and Do / Extend / Block / Skip recommendations.
- Encounter loadouts for Moons, Fight Caves, Royal Titans, MM2/Glough and CoX calibration.
- Shared gear, inventory and supply-bank checklists for herbs, seeds, logs, food, runes and ammunition.

Progress is saved in the browser with local storage; no account or game API connection is required.

## Run locally

Requirements: Node.js 22.13+ and pnpm.

```bash
pnpm install
pnpm dev
```

On Windows, `run-app.bat` starts the app from its own directory and opens the local development server.

## Build

```bash
pnpm build
```
